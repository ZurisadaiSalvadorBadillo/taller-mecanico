Resultado: el backend devuelve 201 Created con el identificador del cliente y el formulario muestra un mensaje de registro exitoso. Ante contacto duplicado devuelve 409 Conflict; ante token o rol inválido bloquea la solicitud.

Patrones aplicados

  • Facade: ClientRegistrationFacade concentra el caso de uso y evita que el controlador coordine infraestructura.
  • Repository: ClientRepository concentra consultas de duplicidad, guardado y listado.
  • Separación de vista: Vue se comunica con una interfaz HTTP centralizada en api.js.
